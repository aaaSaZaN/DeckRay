# DeckRay

[🇺🇸 Read in English](README.md)

Удобный и мощный плагин для Decky Loader на Steam Deck, который позволяет подключать VLESS и Hysteria2 прокси с поддержкой протокола Reality и гибким роутингом трафика.

---

## Возможности

- **Импорт конфигураций** — по ссылке (отдельный узел или подписка) и через QR-код.
- **Переключатель подключения** — включайте и выключайте прокси прямо из меню быстрого доступа (Gaming Mode).
- **Режим TUN** — автоматическая маршрутизация всего трафика системы и игр по умолчанию. Никаких дополнительных ручных настроек.
- **Kill Switch** — блокировка интернет-трафика при внезапном отключении прокси (опционально).
- **Автообновления** — поддержка автоматической проверки и обновления версии xray-core.

## Установка

### Способ 1: Ярлык на Рабочем столе (Основной и самый простой) ✅

> [!IMPORTANT]
> **Требуется пароль Sudo:** Этот скрипт-установщик требует пароль `sudo` (администратора) на вашем Steam Deck, чтобы скопировать файлы плагина и перезапустить службу Decky.
> Если вы ещё не задавали его:
> 1. Откройте приложение **Konsole** в режиме рабочего стола (Desktop Mode).
> 2. Введите команду `passwd` и нажмите **Enter**.
> 3. Введите ваш новый пароль и нажмите **Enter** (обратите внимание: символы *не будут* отображаться на экране при вводе).
> 4. Введите пароль повторно для подтверждения.

Запуск инсталлятора в режиме рабочего стола Steam Deck!
1. Скачай файл [Install-DeckRay.desktop](https://raw.githubusercontent.com/aaaSaZaN/DeckRay/main/scripts/Install-DeckRay.desktop) на свой Steam Deck.
2. Кликни по файлу правой кнопкой мыши → **Свойства (Properties)** → вкладка **Права (Permissions)** → поставь галочку **Является исполняемым (Is executable)**.
3. Дважды кликни на ярлык и выбери **Запустить (Run / Execute)**. Скрипт сам скачает последнюю стабильную версию плагина, установит все необходимые файлы и настроит систему.


### Способ 2: Ручная установка (Пароль Sudo не требуется) 🔒
*Идеальный вариант, если у вас нет пароля `sudo` и вы не хотите его создавать.*
1. Скачай `.zip` архив [последнего релиза](https://github.com/aaaSaZaN/DeckRay/releases/latest).
2. Зайди в **Настройки Decky Loader** → раздел **Разработчик (Developer)** → **Установить плагин по URL (Install Plugin from URL)** и вставь ссылку на архив.

## Как это работает

По умолчанию DeckRay автоматически перенаправляет весь твой сетевой трафик через виртуальный сетевой интерфейс (режим **TUN**). Это гарантирует, что Steam, системные службы и абсолютно любые игры будут работать через прокси как в игровом режиме (Gaming Mode), так и на рабочем столе (Desktop Mode). 

Без режима TUN стандартный SOCKS/HTTP-прокси не покрывает игры и системные сервисы в игровом режиме, так как Steam игнорирует системные сетевые настройки. С DeckRay **режим TUN работает автоматически прямо «из коробки»**, без необходимости каких-либо дополнительных ручных настроек прокси.

## Разработка

Если ты хочешь доработать плагин или собрать его из исходного кода самостоятельно:

### Требования
- Node.js v18+
- pnpm v9+ (обязательно)

### Сборка
```bash
# Установка зависимостей фронтенда
pnpm install

# Компиляция React/TypeScript фронтенда в dist/
pnpm run build
```

Python-бэкенд написан полностью на стандартных библиотеках SteamOS/Decky Loader и не требует установки сторонних pip-пакетов.

### Структура проекта
Краткое описание дерева каталогов и файлов плагина:
```
deckray/
├── backend/
│   ├── src/          # Бэкенд на Python (управление Xray, TUN, Kill Switch, настройки)
│   └── static/       # Ресурсы веб-сервера импорта подписок через QR-код
├── docs/             # Страницы документации GitHub Pages и руководства
├── scripts/          # Скрипты авто-установщика (.desktop и shell-скрипт)
├── src/              # Фронтенд на React / TypeScript для Игрового режима SteamOS
├── main.py           # Точка входа бэкенда плагина (Python)
├── plugin.json       # Метаданные плагина Decky Loader и права доступа
├── package.json      # Зависимости pnpm и скрипты компиляции фронтенда
└── tsconfig.json     # Конфигурация компилятора TypeScript
```
